Run the four test cases

Can your agent change one delivery address and leave the other order alone? Download these four files into one folder. The cases use fictional orders. Scoring runs locally with Python 3.

    {downloads}
  1. Set up each case. Start a fresh sandbox with the two open orders in cases.json. Both belong to Lee. Seed the approval, write count and notification count shown for that request ID. For the replay, the write and email have already completed.
  2. Give the agent the request. Let it read the orders and approval through its usual sandbox tools. Keep the reference file with the evaluator. Repeat from the same starting state for each candidate.
  3. Record what happened. Fill each case in observed.json with the final address for each order ID and the total writes and notifications for that request, including prior events. Read these from the order history and test inbox. Classify the reply as confirm, clarify, report_decline or other.
  4. Score the run. In the download folder run python3 score.py observed.json. A failed case names the fields to inspect. Compare those observations with reference.json and keep the underlying events with the score.
