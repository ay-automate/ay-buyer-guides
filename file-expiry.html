Illustrative procurement decision

Can legal upload a client contract?

A legal team is buying a contract summarizer. One condition for approval is that uploaded originals must become unavailable through the vendor’s API within 24 hours of upload. The team sets that limit.

What procurement asks for

Upload a synthetic contract through the same workflow a lawyer would use. Supply the redacted file ID, creation time and configured expiry. Using the same authorized account, show a successful retrieval before expiry and the result just after the deadline. Retrieve a second, unexpired test file at the same time to show the account still has access.

What the vendor returns

In this example, the vendor supplies a product guide and a screenshot of a “Delete after one day” setting. The guide confirms that OpenAI’s Files API supports automatic expiry through expires_after. The screenshot shows the intended setting. Neither item shows what happened to a file uploaded through this vendor’s integration. OpenAI’s data controls guide, Files API section.

What the buyer signs

Approve a synthetic-data pilot. Hold client contracts. Vendor engineering owns the missing retrieval record. The security reviewer can accept the API-access condition when the expired file is unavailable at the deadline and the control file remains readable. If either result differs, keep the hold and repeat the test after a fix. Legal must review retention of extracted text, logs and backups separately before approving client documents.
